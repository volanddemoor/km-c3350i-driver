# KONICA MINOLTA Universal PS driver — bizhub C3350i

Офіційний драйвер Konica Minolta (Universal PS, v3.9.1310.0, win_x64),
завантажений з офіційного сайту виробника. Викладено тут лише для
використання скриптом розгортання принтера `KM Korytarz`
(192.168.0.192) на кількох ПК — не для публічного поширення поза цією
метою.

Джерело: офіційна сторінка завантажень Konica Minolta для bizhub C3350i
(розділ Drivers → Universal Printer Driver → PostScript).

Використання — див. `install-km-printer.ps1` в релізах цього репозиторію.
